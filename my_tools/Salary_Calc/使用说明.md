# 知薪 · Salary Studio

按照 README 实现的本地薪资测算界面。中文优先使用楷体，英文及数字使用 Cascadia Code / Consolas 等宽字体。无需安装依赖。

## 启动

在项目目录运行 `npm run dev`，浏览器访问 http://127.0.0.1:3000 。也可直接打开 `index.html`；推荐使用本地服务，以获得稳定的本地存储行为。

### 实时保存到项目根目录

点击右上角“设置”，在弹窗的“配置保存”中打开“自动保存个人配置”开关，默认关闭。开启时立即把当前全部有效配置写入根目录的 `personal-config.json`；以后参数修改会在约 300 毫秒后自动同步，保存状态可在设置中查看。文件涵盖薪资、城市、花销、房贷、车贷、收入秒表、发薪日、名言、链接和界面偏好。浏览器本地保存继续保留。

其他浏览器通过同一个本地服务打开项目时，会先读取项目文件，再初始化界面；项目同步开启时优先使用文件里的配置，不用逐个浏览器重新导入。开关状态也保存在该文件中。关闭开关后保留已有文件，后续仅保存到当前浏览器，其他浏览器也不再自动加载这份项目配置。可点击“加载项目配置”读取最新版本。

此功能需要本地 Node 服务，直接打开 `index.html` 不能写入项目目录。修改服务端代码后请重启 `npm run dev`；页面若提示服务不支持保存，可在重启后点击“重新连接本地服务”。首次开启前不会创建项目配置文件。

写入采用临时文件后替换的方式，避免写到一半留下不完整 JSON。不同浏览器或窗口同时修改时，会检测版本冲突、暂停旧窗口同步并提示加载最新项目配置；浏览器中的修改仍保留。读写失败会显示失败状态并可重试，不会显示成保存成功。配置文件与临时文件已加入 `.gitignore`；文件保存的是本机配置，不进行云端同步。

## 功能

- 收入总览：年到手、月均工资、税前收入、月度柱状图、收入占比。
- 累计预扣个税；年终奖单独计税或在 12 月并入综合所得。
- 个人、公司六项缴纳比例与金额；默认基数按城市上下限计算，自定义基数按输入值计算。
- 月度明细、CSV 导出、年度税率表及政策来源链接。
- 城市管理界面：添加或修改城市、缴纳上下限、个人及公司比例、医疗附加费、参数更新日期。
- 当前浏览器自动保存，JSON 配置导出和导入，导入时验证格式和数值。
- 桌面、平板及手机布局，键盘操作与弹窗。
- 社保与公积金可分别开启自定义基数；关闭后使用城市默认范围。
- 专项附加扣除及全年一次性奖金各有独立开关。奖金支持一次性金额或“当前月薪 × 额外奖励月数”；例如奖励 2 个月，即 12 个月工资之外再增加 2 个月奖金。
- 花销与结余：自定义新增、编辑、删除花销；支持每月固定支出和指定月份支出，查看分类占比、每月结余与累计结余，导出全年收支 CSV。
- 加班费独立工具：输入工资基数、每月工作日 / 休息日 / 法定节假日的天数与每天加班小时，支持休息日补休开关以及全年持续月数。
- 页脚名言支持点击或键盘切换，不会连续显示相同的一句。

配置文件已升级为版本 3，包含花销、加班、名言与外部链接设置，仍支持导入版本 1、2。旧版的统一自定义基数开关会迁移为两个状态相同的独立开关；旧版的奖金与扣除保持启用。旧配置默认不分摊奖金、不把加班费计入工资，并补入默认名言及链接。关闭奖金或扣除不会清空已填写的金额。恢复默认设置仅恢复薪资表单，保留城市、花销、加班和内容管理数据。

## 新增的显示与管理设置

- 收入总览与五险一金明细均展示个人、公司各项比例以及双方比例合计。双方比例可在城市编辑弹窗分别修改，无需相同。合计是名义比例相加；社保基数与公积金基数不同时，不能直接用工资乘总比例得到总金额，固定医疗附加费也不计入比例。
- 收入总览的“显示设置”可开启年终奖按月分摊。先按原计税方式计算全年奖金的相关税额，再将奖金和相关税额以分为单位分配到各月，不改变全年税前、税额、个人缴纳或到手总额。合并计税时，奖金相关税额为含奖金与不含奖金的全年综合所得税差。实际付款和预扣口径仍假设奖金 12 月发放；分摊只用于月度图表、明细、CSV 和收支规划，界面会标注。
- 同一“显示设置”内可开启“全年预计计入单边公积金”，默认关闭。单边取个人缴纳额：全年参考总额 = 全年现金到手 + 个人每月公积金 × 12，不加公司公积金。开启后卡片会标明现金和公积金各自金额；月度到手、税额、收入占比、CSV 和生活结余仍按现金口径计算。此开关自动保存并随 JSON 配置导入导出，已有版本 3 配置缺少此字段时默认关闭，其他数据保留。
- “工资之外，还有一份积累”整张卡片可点击或用键盘跳转到五险一金明细。
- 加班费页面展示普通时薪、1.5 倍、2 倍及 3 倍时薪，以及不同加班类型的金额。
- 可开启“加班费计入月薪并纳税”，指定起算月份与持续月数。对应月份的加班费并入工资，重新累计计算个税，年度到手及结余同步更新。加班工资基数独立输入，奖金奖励月数只按基础月薪计算；社保与公积金基数仍按基础月薪或自定义值估算，不自动因加班而调整。起算月份加持续月数不得超出本年度。
- “12 月奖金月照常计入加班费”默认开启：开启工资计入且 12 月有奖金时，即使原持续范围只到 11 月，12 月也按同样安排计入加班费、税额及年度结余，标签显示“含奖金 + 加班费”；范围已包含 12 月时不重复计入。关闭此选项后严格按起算月份及持续月数计算。
- 侧栏“名言与链接管理”提供名言 / 人生哲理及外部工具的新增、编辑、启用 / 停用、删除与上下排序。默认内置 24 条文字和 3 个外部工具。启用的名言点击随机切换，不会连续重复同一条；仅有一条时保留该条，全部停用则隐藏名言区。外部工具按管理顺序显示在页末，点击在新标签页打开。链接支持 http / https，拒绝脚本地址和含账号密码的地址。
- 内容管理仍是本地浏览器管理界面，数据保存在 localStorage，可通过 JSON 文件跨浏览器备份。

## 日期、发薪日与政策指南

页面顶部在所有功能页展示实时时钟、公历日期、星期、农历月日、干支年、生肖与年内日期进度。统一使用北京时间（Asia/Shanghai），每秒刷新，并在标签页恢复可见时立即更新。时间来源为设备时钟；农历使用浏览器内置的中国农历历法，支持闰月，不支持该历法的浏览器会显示明确提示。

“设置发薪日”支持每月 1—31 日。目标月份没有该日期时，先取该月最后一天；可再选择周六、周日不调整、提前到周五或顺延到周一。周末规则不处理国家法定节假日与调休，不表示单位的实际到账承诺。倒计时按北京时间自然日差计算，当天显示 0 天。跨月调整会同时考虑前一个名义发薪月份，避免漏掉例如“1 月 31 日顺延到 2 月 2 日”的情况。

发薪设置保存到本地，并随版本 3 JSON 配置导入导出；旧配置缺少 payday 字段时默认每月 10 日、周末不调整，保留其他已有设置。该设置不改变薪资税额或测算月份。

侧栏“保障政策指南”或页内“政策指南”可打开独立说明页，包含六项保障的缴费主体和用途、企业年金与职业年金的区别、比例和基数口径、常见问题及官方原文链接，附资料核验日期。目录支持跳转，问答可展开。政策页面不会自动替换城市参数。当前工资计算仍只涵盖五险一金，年金仅作政策说明，未自动加入到手工资、个税或结余计算。

日期和发薪日的测试覆盖北京时间跨午夜、农历新年与闰月、闰年、月末、周末提前 / 顺延、跨月和跨年。农历样例可对照香港天文台的[公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)；时钟本身不请求外部服务。

## 房贷计算器

侧栏“房贷计算器”提供独立房贷页，支持商业贷款、公积金贷款、组合贷款，贷款金额可直接输入，也可通过房屋总价 / 单价与面积、首付比例推算。贷款和房屋总价支持“万元 / 元”切换，默认万元，切换时自动换算已有数值；内部计算、JSON 和 CSV 始终使用元，万元输入保留到小数点后六位以对应分。房屋单价、家庭收入和费用仍以元输入。期数使用月，可快捷选择 10 / 20 / 30 年，允许 1—600 个月以便自定义模拟；这不是银行可批贷款年限或额度的承诺。首次还款月份使用独立年份、月份选择器，可用左右按钮跨月、跨年调整。

商贷年利率可直接填写，也可设置 LPR 加减点，1 BP 等于 0.01 个百分点。公积金利率单独填写。默认利率全部为演示值，不代表最新报价，不联网获取或自动匹配首套、二套、城市及公积金额度。按填写的年利率除以 12 作为月利率，全期保持不变；不模拟后续重定价。组合贷的两笔贷款按各自利率和金额计算，使用同一期数，再汇总月供。

结果同时比较等额本息、等额本金，显示首月、末月、本金、利息、本息总额及利息差。逐月利息、月供与本金按分计算，末期结清尾差。曲线可切换月供、剩余本金、累计利息，拖动滑块查看任意一期的两种方案及本金 / 利息构成。下方完整还款表可按年份筛选，CSV 始终导出当前还款方式的全部期数，组合贷包含商贷和公积金月供分项。

点击“收入、花销与提醒 · 设置”或结果区的“修改收支”打开独立弹窗，填写家庭到手月收入、房贷外花销、购房后可用应急存款和收入下降比例。修改即时保存，可点击“完成设置”、右上角关闭或 Esc 收起弹窗。现金流按最高月供保守估算，显示月供收入比、月结余、收入下降后的结余和零收入情况下存款覆盖月数。此处不与工资或花销记账自动联动，避免把房贷重复扣除。默认显示“贷款买房就是套牢”的个人提醒，可自行编辑或关闭。

房贷参数随其他配置保存在本地并支持 JSON 导入导出；旧配置缺少 mortgage 字段时补入演示设置，保留其他设置。恢复房贷默认值只影响房贷。测算不包含交易税费、装修、保险、提前还款或房价涨跌，实际账单以银行合同为准。

### 曲线、日期与界面设置

房贷和车贷曲线的“纵坐标刻度设置”可选择自动刻度或自定义下限、上限、刻度间隔。月供、剩余本金、累计利息三种指标分别保存刻度；上下限与间隔以元填写，刻度最多 12 格，超出范围的曲线裁切并显示提示。自动范围按当前所有还款方案的最小值和最大值，上下各预留数据跨度的 10%，留白至少为最大金额的 1% 或 1 元，再向外取整到整齐的刻度；不固定从 0 开始，下限不小于 0。数值相同或只差几分钱时仍保留合理的显示范围。自动模式的输入框展示当前实际范围，关闭自动后可从此范围继续微调；较大金额以万标注。恢复贷款默认参数会同时恢复该贷款的自动刻度。

顶部“今日与发薪日”右侧按钮可整体收起 / 展开时间、农历和发薪日卡片。折叠偏好会保存到浏览器并包含在 JSON 配置中；旧配置默认展开。标签导航去掉可见滚动条和竖向滚动，窄屏仍可横向滑动，键盘方向键也能切换。

## 车贷计算器

独立车贷页支持填写裸车价、首付比例、期数、首次还款月份，车价支持万元 / 元切换。期数可选 12 / 24 / 36 / 60 期，也可手填 1—120 期，范围仅供模拟。所有利率和费用默认值为演示数据。

- 按剩余本金年利率：支持等额本息、等额本金，并在曲线上比较。
- 按原始本金月费率：每月分期费用 = 初始贷款本金 × 月费率，本金按期均摊，费用不随本金下降。
- 零利息：本金按期均摊；手续费仍单独计入购车支出。

手续费、购置税、首年保费、上牌及其他费用均由用户填写，假设提车时一次支付、不计入贷款本金。提车支出 = 首付本金 + 上述一次性费用；购车总支出 = 裸车价 + 全期利息 / 分期费 + 上述一次性费用。计算不包含日常用车支出、续保、尾款方案、提前还款和后续利率变化。

“含手续费的有效年化估算”用贷款本金扣除贷款手续费后的净额与逐月还款现金流求月度内部收益率，再按复利折算成年化。它与直接把月费率乘 12 不同；全款购车或手续费不低于本金时显示不适用。贷款每期金额按分计算，末期结清本金尾差。

车贷有独立还款曲线、自定义纵坐标、逐月明细和完整 CSV 导出，参数随 JSON 一起保存，与房贷、薪资和生活记账互不覆盖。

## 收入秒表

“今日与发薪日”下方增加收入秒表，随顶部卡片整体折叠。默认跟随工资测算的月均工资到手金额（不含奖金和公积金）；也可在“设置秒表”中填写独立月收入。可设置月计薪天数、上下班时间、午休是否暂停、午休时段、每周工作日和午饭小目标。默认 09:00—18:00、12:00—13:00 午休、周一至周五、月计薪 21.75 天、目标 30 元，均为可编辑的估算设置。

每日收入基数 = 月收入 ÷ 月计薪天数；每秒收入 = 每日基数 ÷ 当天有效计薪秒数。今日预计收入按当天已经过的有效计薪时长计算，午休暂停、下班封顶、休息日归零，午夜按北京时间切换新一天。后台标签恢复或重新打开页面时，直接从设备时间重算，不依赖页面持续打开。仅支持当天班次；工作星期不自动识别法定节假日及调休。

秒表仅用于展示估算，不表示到账，不改变工资、税额、花销和年度结余。设置自动保存在本地并包含在 JSON 导入导出中；旧配置缺少 incomeClock 时补入默认设置。

秒表旁新增“下班倒计时”，与秒表共用班次、工作日和北京时间，每秒刷新。上班前显示距开工时间，工作中（含午休）显示距下班时间，下班后显示“下班快乐”，休息日切换为休息文案，不出现负数倒计时。顶部日期、时间、发薪日及秒表的说明、数字和操作入口同步放大。

## 范围与计算口径

此版本为本地界面，城市与内容等配置默认保存在浏览器 localStorage，并可选择通过本地服务同步到项目根目录的 JSON 文件。不包含生产后端、身份验证或跨设备数据库。浏览器隐私模式或清理站点数据可能导致仅保存在浏览器的设置丢失，可开启项目保存或导出 JSON 备份。

内置四座城市的基数和比例均为演示值，不代表最新城市政策。2026-10-22 是示例录入日期。投入实际使用前，请在城市管理中按官方文件配置。

测算固定为 2026 年，假设居民个人 1 月至 12 月连续任职、固定月薪、月度扣除不变、奖金在 12 月发放。个税基本减除费用每月 5,000 元，年度 60,000 元。假设填写的个人五险一金及专项附加扣除可全额税前扣除，不自动判断法定资格和扣除限制。工伤、医疗、生育等公司缴纳比例因城市和单位而异，应手动核实。

单独计税时，年终奖除以 12 定位月度档位，再用奖金全额乘税率减月度速算扣除数。实现中等价使用年度档位定位奖金全额，速算扣除数除以 12。单独计税政策现行适用至 2027-12-31。

“月均到手薪资”是 12 个月工资减个人缴纳、工资个税的均值；不包含奖金收入。奖金并入综合所得时，该指标包含合并产生的税负。公司缴纳只做额外保障展示，不计入个人税前或到手收入。各项月度缴纳及个税四舍五入到分。若个人缴纳超过工资，结果允许为负并展示提醒。

## 验证

运行 `npm test`。测试覆盖七档税率、奖金临界点、累计预扣、年度收支平衡、基数上下限、自定义基数、医疗附加、零工资及金额精度。

花销结余 = 工资测算的税后到手收入 − 生活花销。每月固定支出全年计 12 次，指定月份支出计 1 次；可出现负结余。月均花销将全年支出除以 12，同名花销合并展示占比；不额外扣除已在工资中计算的社保与个税，也不包含期初存款、投资收益及公积金提取。

加班费按标准工时制估算，小时基数 = 月加班工资基数 ÷ 21.75 ÷ 8。工作日 150%、未补休的休息日 200%、法定节假日 300%；补休开关仅影响休息日。全年估算 = 本月加班费 × 持续月数，不自动读取实际日历或假期。输入的三类天数应互斥，周六需根据实际排班归类。时薪保持完整精度，各项费用最终四舍五入到分。默认独立计算税前加班费，只有开启“计入月薪并纳税”后才加入工资和年度结余。若低基础工资与部分月份加班导致累计应纳税额回落，月表负税额表示估算应退额，实际退税需按年度汇算办理。实际基数与适用规则请结合劳动合同和当地规定确认。
